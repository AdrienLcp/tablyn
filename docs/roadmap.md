# Roadmap

What Tablyn is meant to become. Read it when deciding what to build next — not
when working on something already decided.

The checkboxes are a plan, not a status report: verify against the tree before
trusting one.

## Core features (MVP)

- [ ] **Shortcut grid** — a grid of user-defined shortcuts (name + URL +
  optional image)
- [ ] **Add / edit / delete shortcuts** — modal or inline form
- [ ] **Custom images** — upload or URL for each shortcut's icon
- [ ] **Custom favicon** for the new tab page
- [ ] **Custom tab title** (default: "Tablyn")
- [ ] **Persistent storage** — every setting and shortcut in
  `browser.storage.local`
- [ ] **Export / import config** — all settings and shortcuts as a JSON file

## After the MVP

### Ambiance

- Clock, digital or analog
- Dynamic greeting ("Good morning" / "Good evening")
- Customizable background — solid colour, gradient, or uploaded image

### Productivity

- Search bar (Google / DuckDuckGo / custom engine)
- Local weather widget (OpenWeatherMap free API)
- Quote of the day (local JSON or free API)

### Visual polish

- ~~Light / dark theme~~ — done: 6 presets × 2 modes, custom accent, system mode
  detection
- Drag & drop to reorder shortcuts

### Power user

- Keyboard shortcuts (1-9 to open a link directly)
- Import / export settings as JSON
- Open tab counter
